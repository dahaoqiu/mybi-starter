# myBI 部署手册（v1.0-lite）

默认形态：**JDK 17 + 后端 jar + 前端 web + SQLite 元库**。业务数据在客户自己的 MySQL / SQL Server。

## 1. 环境要求

| 项 | 要求 |
|---|---|
| OS | Linux x86_64 / Windows Server 2016+ |
| JDK | **17**（必须；系统默认若是 8，请设 `JAVA_HOME`） |
| 内存 | ≥1 GB（建议 2 GB+） |
| 磁盘 | ≥2 GB 可用（含日志与备份） |
| 端口 | `8080`（可改） |

## 2. 安装前自检

```bash
# Linux / macOS
chmod +x deploy/preflight.sh
./deploy/preflight.sh

# Windows
powershell -File deploy/preflight.ps1
```

9 项全部为「通过」或可接受的「警告」后再安装。失败项按脚本给出的一句话修复。

## 3. 安装步骤（≤30 分钟）

发布包由工程侧生成：`powershell -File scripts/assemble-release.ps1 -Version 1.0.0-lite` → `releases/<version>/`。

1. 解压/拷贝发布包到目标目录，例如 `/opt/mybi` 或 `D:\mybi`
2. 确认目录内有：`backend.jar`、`install.ps1` / `install.sh`、`preflight.*`、`THIRD-PARTY-LICENSES.md`、`docs/`
3. 执行安装：
   ```bash
   # Linux
   cd /opt/mybi
   chmod +x install.sh deploy.sh backup-meta.sh preflight.sh
   ./preflight.sh && ./install.sh
   ```
   ```powershell
   # Windows（推荐）
   cd D:\mybi
   powershell -ExecutionPolicy Bypass -File .\preflight.ps1
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
4. 浏览器打开 `http://服务器IP:8080`（前端需 Nginx 反代 `web/`，或开发期用 Vite 代理）
5. 默认账号：`admin` / `admin123` —— **登录后立即改密**
6. （可选）导入授权：`license/license.json` 或 `POST /v1/license/import`

### Docker

```bash
# 将 backend.jar、web/ 放到 deploy/ 后
docker compose -f deploy/docker-compose.yml up -d
```

## 4. 配置说明

| 路径 | 是否可覆盖 | 说明 |
|---|---|---|
| `data/` | **永不覆盖** | SQLite 元库 `mybi.db` |
| `conf/` | **永不覆盖** | 本地配置 |
| `license/license.json` | **永不覆盖** | 客户授权 |
| `backend.jar` / `web/` | 升级时替换 | 程序与页面 |

密钥：生产环境设置 `MYBI_LICENSE_SECRET`（与签发时一致）。

## 5. 切 MySQL 元库（招标场景）

1. 准备空库，执行 `backend/src/main/resources/db/migration/mysql/V1__baseline.sql`
2. 启动时去掉 sqlite profile，使用 `application.yml` 中的 MariaDB 驱动 URL
3. 驱动已为 `org.mariadb.jdbc.Driver`（兼容 MySQL 5.7/8.0）

## 6. 备份

```bash
./backup-meta.sh
# 或登录后：POST /v1/meta/backup
```

WAL 模式下**不要**直接复制正在运行的 `mybi.db`。

## 7. 验收

- [ ] 能登录
- [ ] 能建业务数据源并执行一条 SQL 数据集
- [ ] 能导出 PDF（文件头为 `%PDF`）
- [ ] `GET /v1/license/status` 返回试用或正式授权状态
