# SQL 参数语法速查（一页 A4）

> 贴 SQL 时只用这 4 种写法；所有值走 `?` 绑定，不拼字符串。

---

## 1. 四种写法

| 写法 | 含义 | 示例 |
|---|---|---|
| `${name}` | 单值 | `WHERE s.dt = ${day}` |
| `${name:like}` | 模糊（自动包 `%…%`） | `WHERE p.sku_name LIKE ${keyword:like}` |
| `${name:in}` | 列表（**模板里不写括号**） | `WHERE st.region IN ${region:in}` |
| `/*IF name*/ … /*END*/` | 参数为空则整段删除 | `/*IF region*/ AND st.region IN ${region:in} /*END*/` |

---

## 2. 三条硬规则

| # | 规则 | 原因 |
|---|---|---|
| 1 | 日期区间用 `>= 开始 AND < 结束` | `BETWEEN` 会漏最后一天（含 23:59:59 之后） |
| 2 | 表名/列名不能做参数 | 绑定只支持值，不支持标识符 |
| 3 | 只允许单条 `SELECT` / `WITH` | 写操作 → E2009；多语句 → E2008 |

---

## 3. 旧写法（兼容）

| 旧 | 现在 |
|---|---|
| `:name` | `${name}` |
| `#{name}` | `${name}` |

系统会先归一化再绑定；**新代码请直接用 `${}`**。

---

## 4. 常见错误码

| 码 | 含义 | 处理 |
|---|---|---|
| E2001 | 参数未定义 | 报表里「从 SQL 扫描」补齐参数 |
| E2002 | 必填未填 | 补参数；可选条件用 IF 块 |
| E2003 | 类型不对 | 日期用 `yyyy-MM-dd` |
| E2008/E2010 | 多语句 | 只留一条 |
| E2009 | 非只读 | 去掉 DELETE/UPDATE |
| E1005 | 超时（30s） | 缩时间窗、加索引 |

---

## 5. 示例（可直接跑）

```sql
SELECT p.category AS 品类, SUM(s.qty) AS 销量
FROM fact_sale s
JOIN dim_product p ON p.sku_id = s.sku_id
JOIN dim_store st ON st.store_id = s.store_id
WHERE s.dt >= ${startDate} AND s.dt < ${endDate}
  /*IF region*/ AND st.region IN ${region:in} /*END*/
GROUP BY p.category
ORDER BY 销量 DESC
LIMIT 5
```

参数：`startDate`(date) `endDate`(date) `region`(multiple, 可选)
