# myBI 升级说明

## 原则

**只替换程序，不碰客户数据。**

| 可替换 | 永不覆盖 |
|---|---|
| `backend.jar` | `data/`（含 `mybi.db`） |
| `web/` | `conf/` |
| 迁移脚本（只 ADD） | `license/license.json` |

## 升级步骤

1. 备份元库  
   ```bash
   ./backup-meta.sh
   # 或 POST /v1/meta/backup
   ```
2. 执行升级脚本（Linux）：  
   ```bash
   ./deploy.sh /path/to/new-backend.jar /path/to/new-web
   ```
3. 查看 `logs/boot.log`，确认 `Started ReportApplication`
4. 登录验证：打开一张旧报表 → 查询 → 导出 PDF

## 回滚

1. 停服务  
2. 用 `backup/backend-*.jar` 换回旧 jar；`web` 若有 `web.prev` 可换回  
3. **一般不回滚数据库**（迁移只加不改）；若必须：停服后用 `backup/mybi-*.db` 覆盖 `data/mybi.db`，并删除 `-wal`/`-shm` 后启动

## 版本与许可

- 升级不改变授权文件；到期仍为只读  
- 随包核对 `THIRD-PARTY-LICENSES.md` 是否更新  

## 失败处理

| 现象 | 处理 |
|---|---|
| 端口占用 | `preflight` 查占用进程，或改 `--server.port` |
| 启动报 E3001 | 授权被改过，重新导入签发文件 |
| SQLite busy | 检查是否多实例写同一 `mybi.db` |
