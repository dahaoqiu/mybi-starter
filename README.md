# myBI 集成示例（Apache-2.0）

> 这是**示例与工具仓库**，不是引擎本体。
> 引擎本体（后端 + 前端）为商业软件，不在本仓库开源；本仓库只放**可以自由使用**的集成材料。

---

## 内容

| 目录 | 内容 | 许可 |
|---|---|---|
| `schema/` | 中间库建表脚本（零售 4 表 / 制造 5 表） | Apache-2.0 |
| `examples/` | 可跑的示例数据集 SQL（30 条认证问句节选） | Apache-2.0 |
| `deploy/` | docker-compose、preflight 自检脚本、备份脚本 | Apache-2.0 |
| `docs/` | 部署手册、参数语法速查、错误码对照 | Apache-2.0 |
| `client/` | 前端嵌入示例（iframe + token 的最小实现） | Apache-2.0 |

---

## 为什么只开放这些

报表最难的不是"画图"，是**参数、口径、导出、权限、交付**。
我们把**集成层**开放出来，方便你评估与接入；引擎的调度、权限、白标、AI 问数等实现保持商业授权。

---

## 使用方式

```bash
git clone <repo>
cd examples && 按 schema/ 建表、导入示例数据
# 用引擎（商业版）连接你的中间库，按 docs/参数语法 配置数据集
```
